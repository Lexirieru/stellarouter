# User Onboarding Form (Level 5)

Create the Google Form with these questions (2 minutes), then link it here and
put the link in the console's Feedback widget / README.

**Form title:** Stellarouter — Testnet User Feedback

| # | Question | Type | Required |
|---|---|---|---|
| 1 | Name | Short answer | yes |
| 2 | Email | Short answer | yes |
| 3 | Stellar wallet address (G…) | Short answer | yes |
| 4 | Rate your product experience | Linear scale 1–5 | yes |
| 5 | What worked well? | Paragraph | no |
| 6 | What broke or was confusing? | Paragraph | no |
| 7 | What feature should we build next? | Multiple choice: Streaming responses · More models on testnet · Fiat top-up (anchor) · API SDK/templates · Other | no |

**Response sheet:** link the Form to a Google Sheet; the objective columns for
the on-chain cohort are pre-exported in [users-import.csv](./users-import.csv)
and [users-feedback.xlsx](./users-feedback.xlsx) — join on wallet address.
Ratings and written feedback come from real respondents only (the in-product
Feedback widget mirrors the same fields into the gateway's `/feedback` store).
